DIAGRAM 02 · CUSTOMER JOURNEY

Guided conversation structure

Current implementation limitation: purpose (self/gift) and usage (daily/occasion) are collected and saved but do not yet affect the guided recommendation ranking. Gender, size and recognized note preferences/dislikes do affect it. Returning customers currently skip the recipient and usage questions.

LLM and speech transcription integrations require configuration. The code’s default LLM identifier is meta-llama/Llama-3.1-8B-Instruct:novita; this document records the configured default, not a verification of provider availability. Browser speech recognition is provider-managed and is not a direct Whisper call.

REFERENCE · DATA AND DEPENDENCIES

Storage, other APIs and failure paths

ComponentRole
localStorageCustomer name, discovery choices, preferences, product IDs, language and speaker preference.
sessionStorageRecent conversation turns, restored within the browser session.
Local knowledge filesCatalog snapshots, workbook exports, product knowledge and intent examples. Core retrieval is lexical/rule-based; no vector database is configured here.
GET /api/healthSimple backend health response.
Product linkOpens the storefront route /productDetails/category/name/id. This is navigation, not an LLM call.
Separate discovery/gifting website APIsdiscover.html and gift.html call https://recommendation.mansamworld.com/recommend. gift.html also uses https://ae.mansamworld.com/api/public/userdreams and /api/public/isd. These are separate from the chatbot’s /api/chat flow.
Chat request failureBrowser request timeout is 6 seconds per attempted URL. Generic chat can fall back to local canned answers; when a discovery size is saved, it reports an error instead.
No matching sizeBackend returns discovery_no_match; browser returns to the size question. Available sizes are derived from matching catalog records.
Microphone or transcription failureDisplays a voice error; customer can continue with typed input.
